# Deepfake Video Detection using ResNeXt + LSTM

A deep learning-based system for detecting deepfake videos using a combination of ResNeXt and LSTM models. It analyzes face features and their temporal patterns to classify videos as **Real** or **Fake**.

## 🔍 Features

- Face detection using MTCNN
- Feature extraction with ResNeXt-50
- Sequence learning with LSTM
- Flask-based web app for uploading and predicting videos
- Displays prediction label and confidence score

## 🧠 Model Architecture

- **CNN**: ResNeXt-50 for face feature extraction
- **RNN**: LSTM for sequence modeling
- Binary classification (Real / Fake)
